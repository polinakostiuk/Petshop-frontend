# PetShop: фронтенд

Простий фронтенд (HTML + CSS + JavaScript), який показує каталог товарів із API бекенду.

Бекенд: [Petshop](https://github.com/polinakostiuk/Petshop).

## Як запустити проєкт

| Частина | Адреса |
|---|---|
| Бекенд (Django) | http://127.0.0.1:8000 |
| Фронтенд | http://127.0.0.1:3000 |

1. Запустіть бекенд за інструкцією в його README (`python manage.py runserver 8000`).
2. У папці цього репозиторію виконайте:

```bash
python3 -m http.server 3000 --bind 127.0.0.1
```

3. Відкрийте http://127.0.0.1:3000. Не відкривайте `index.html` подвійним кліком: CORS на бекенді дозволяє запити лише з `http://127.0.0.1:3000`, `http://localhost:3000` і `63342` (PyCharm).
